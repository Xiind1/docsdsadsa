# Как запустить Minty Mobile

## Установка <a href="#ustanovka" id="ustanovka"></a>

1. **Ссылка для загрузки:** [ссылка для загрузки](https://apk.kindawindy.today/download)

{% hint style="info" %}
Если браузер блокирует загрузку, разрешите её вручную. Обычно появляется кнопка **Download anyway**.
{% endhint %}

2. Откройте скачанный **M-Loader.apk**.
3. Если Android предупреждает об установке из неизвестного источника, нажмите **Settings** и включите **Allow from this source**, затем вернитесь назад и продолжите установку.
4. Если **Play Protect** блокирует установку, нажмите **Install anyway**.

{% hint style="info" %}
Лоадер обновляется автоматически. Если на экране загрузки появляется обновление, дождитесь завершения. Он переустановится и откроется сам.
{% endhint %}

## Первый запуск <a href="#pervyi-zapusk" id="pervyi-zapusk"></a>

Откройте лоадер и дождитесь завершения экрана загрузки.

<figure><img src="../.gitbook/assets/image (240).png" alt="" width="237"><figcaption></figcaption></figure>

{% hint style="warning" %}
**Если лоадер завис на экране загрузки**, попробуйте:

* Выключить и включить Wi-Fi или мобильный интернет.
* Отключить VPN или блокировщик рекламы, если они фильтруют трафик.

**Рекомендация:** Используйте VPN, так как интернет-провайдер может блокировать сервер.
{% endhint %}

## Установка модифицированной игры <a href="#ustanovka-modificirovannoi-igry" id="ustanovka-modificirovannoi-igry"></a>

1. Перейдите на вкладку **Game Manager**
2. На карточке проекта нажмите **Authenticate** и сначала вставьте свой ключ.
3. Нажмите **Not Installed**, подтвердите действие и подождите.

<figure><img src="../.gitbook/assets/image (241).png" alt="" width="235"><figcaption></figcaption></figure>

4. Во всплывающем окне будут шаги **Uninstalling → Downloading → Unpacking → Installing**.
5. Когда появится статус **Installed**, модифицированная игра готова.

{% hint style="info" %}
Это делается только один раз. Игра сохраняет все уже загруженные ресурсы, поэтому полной повторной загрузки не будет.
{% endhint %}

## Запуск <a href="#inzhekt" id="inzhekt"></a>

1. Откройте лоадер и нажмите **Start**.
2. Если появляется **"Close the game first"**, полностью закройте игру и снова нажмите **Start**.
3. Дождитесь уведомления **"Loaded!"**, затем откройте игру.
