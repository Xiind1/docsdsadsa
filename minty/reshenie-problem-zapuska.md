1. Установите DirectX, Visual C++, Net Framework 8.0.
2. Отключите Защитник Windows.
3. Отключите брандмауэр и защиту сети.
4. Отключение компонентов Core Isolation
   1. Откройте параметры Windows (нажмите Win + I)
   2. перейдите в Конфиденциальность и защита → Безопасность windows → Безопасность устройства и выключите все доступные параметры защиты.
   3. Перезагрузите ПК — после перезапуска станет доступен пункт Список заблокированных уязвимых драйверов (Майкрософт)
   4. Отключите его и снова перезагрузите компьютер для применения изменений.
5. Удалите все имеющиеся антивирусы.
6. Закройте Faceit, Riot Games и Blizzard launcher и удалите их из автозагрузки.
7. Закройте все оверлеи Riva, FPS, Action, Bandicam и т. д.
8. Закройте все игры, в которых есть античиты, такие как EAC, BE, ACE, Vanguard и т. д.

{% hint style="warning" %}
**После выполнения этих действий перезагрузите компьютер! Если что-то все еще не работает, пройдите каждый шаг еще раз!**
{% endhint %}
