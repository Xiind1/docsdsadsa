**Подготовка системы к первому запуску продукта:**

1. Отключите **Windows Defender**

<figure><img src="../.gitbook/assets/image (140).png" alt="" width="375"><figcaption><p><strong>Выключите защиту в реальном времени</strong></p></figcaption></figure>

2. Окончательно отключите **Windows Defender** с помощью программы dControl

* **Google Drive** - [ссылка для загрузки](https://drive.google.com/file/d/19G3C5Gg1KDr1W05jhwwB6xeMx8PG_IrU/view?usp=sharing) (пароль 1234)
* **Yandex Disk** - [ссылка для загрузки](https://disk.yandex.ru/d/pLPzChHbwskWNQ) (пароль 1234)
* **Mega** - [ссылка для загрузки](https://mega.nz/file/Vr9EUSKB#Sn0bze9l49paasaCZqYPkAodQwo5avSpUWVzo5f4x38)

<figure><img src="../.gitbook/assets/image (141).png" alt=""><figcaption><p><strong>Нажмите "</strong><mark style="color:red;"><strong>Отключить Защитник Windows</strong></mark><strong>" даже если пишется, что он уже выключен</strong></p></figcaption></figure>

3. Полностью удалите (отключение не сработает) любое сторонне антивирусное П.О:                            <mark style="color:red;">**"Kaspersky" / "Avast" / "Avira" / "360 total secure" / "Dr.Web" / "Avast"**</mark>
4. После удаления перезагрузите ПК.

**Запуск продукта:**

{% hint style="danger" %}
**ПРЕДВАРИТЕЛЬНО ОБЯЗАТЕЛЬНО УДАЛИТЕ ПРЕДЫДУЩИЙ ФАЙЛ ЛОАДЕРА И ТОЛЬКО ПОСЛЕ ЭТОГО СКАЧАЙТЕ НОВЫЙ ФАЙЛ И ПЕРЕМЕСТИТЕ ЕГО НА USB-ФЛЕШ НАКОПИТЕЛЬ**&#x20;
{% endhint %}

1. Запустите игру, в настройках игры включите параметр “<mark style="color:red;">**ОТСЕЧЕНИЯ ОККЛЮЗИИ (OCCLUSION CULLING)**</mark>", затем закройте игру.
2. Подключите USB-флеш накопитель к ПК, затем скачайте лоадер по ссылке: [ссылка для загрузки](https://mason-hacks.orion-security.pro/launcher), используя свой ключ, который Вы получили после оплаты, переместите скачанный файл на USB-флеш накопитель.
3. Запустите от имени администратора скачанный файл, в открывшемся окне лоадера выберите Вашу игру, нажмите на неё, далее нажмите кнопку “<mark style="color:red;">**Запустить**</mark>”
4. Дождитесь закрытия лоадера, в случае успешного инжекта лоадер выдаст сообщение с “**галочкой**” и закроется, затем появится дополнительное окно с текстом “**SUCCES: START GAME!**”, нажмите кнопку “**Ок**”, теперь извлеките USB-флеш накопитель, затем запустите <mark style="color:red;">**САМОСТОЯТЕЛЬНО**</mark> игру.
5. После того как игра полностью прогрузится до главного меню заходите на сервер, функция ESP активируется автоматически, ожидайте на сервере до 10 минут для очистки “мусора” из ESP.
6. **Вот и все, можете спокойно играть!**

{% hint style="info" %}
\* Примечание:

Функция ESP работает один сеанс запуска на сервер, т.е вы запустили продукт, загрузились на сервер, играете, для того чтобы сменить сервер для игры с продуктом вам нужно сделать повторный инжект, т.е закрыть игру и заново запустить продукт в соответствие инструкцией

Если вы хотите отключить работу ESP в процессе игры, отключите в настройках игры параметр **"ОТСЕЧЕНИЯ ОККЛЮЗИИ (OCCLUSION CULLING)"**
{% endhint %}
