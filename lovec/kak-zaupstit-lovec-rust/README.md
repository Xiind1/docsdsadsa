### Подготовка системы к первому запуску

1. **Отключение Безопасность Windows**

* Перейдите в параметры системы (вы можете нажать комбинацию WIN + I)
* Откройте **Безопасность Windows**
* Отключите параметр **"Защита в реальном времени"**

<figure><img src="../../.gitbook/assets/image (140).png" alt=""><figcaption></figcaption></figure>

2. **Окончательно отключите Безопасность Windows с помощью программы dControl**

* **Google Drive** - [ссылка для загрузки](https://drive.google.com/file/d/19G3C5Gg1KDr1W05jhwwB6xeMx8PG_IrU/view?usp=sharing) (пароль 1234)
* **Yandex Disk** - [ссылка для загрузки](https://disk.yandex.ru/d/pLPzChHbwskWNQ) (пароль 1234)
* **Mega** - [ссылка для загрузки](https://mega.nz/file/Vr9EUSKB#Sn0bze9l49paasaCZqYPkAodQwo5avSpUWVzo5f4x38)

<figure><img src="../../.gitbook/assets/image (141).png" alt=""><figcaption><p><strong>Нажмите "</strong><mark style="color:red;"><strong>Отключить Защитник Windows</strong></mark><strong>"</strong> </p></figcaption></figure>

3. **Отключите изоляцию ядра.**

* Параметры => Обновление и безопасность => Безопасность Windows => Безопасность устройства => Сведения об изоляции ядра

<figure><img src="../../.gitbook/assets/image (245).png" alt=""><figcaption></figcaption></figure>

4. **Отключите «Защиту на основе репутации»**

* Параметры => Обновление и безопасность => Безопасность Windows => Управление приложениями/браузером => Параметры защиты на основе репутации

<figure><img src="../../.gitbook/assets/image (246).png" alt=""><figcaption></figcaption></figure>

**5. Удаление конфликтующего программного обеспечения**

Следующие программы необходимо **полностью удалить**, а не просто закрыть:

* **Античит FACEIT**
* Любой сторонний антивирус (Avast, Kaspersky, McAfee, ESET, Bitdefender и т. д.)

{% hint style="danger" %}
Если установлен FACEIT AC или сторонний антивирус, продукт **не будет работать** независимо от других настроек.
{% endhint %}

### Запуск по шагам

1. Скачайте лоадер и перенесите его на USB-флешку.

ссылка на лоадер - [https://e.pcloud.link/publink/show?code=kZP6g77Z8vR7Jvl5nb70iwqt4mtKkVkaDd7X](https://e.pcloud.link/publink/show?code=kZP6g77Z8vR7Jvl5nb70iwqt4mtKkVkaDd7X)

2. Удалите все копии лоадера с компьютера — из «Загрузок», «Рабочего стола» и сам архив, затем очистите «Корзину». Оставшаяся копия — причина бана и ошибки Bad HWID.
3. Запустите лоадер с флешки от имени администратора.
4. Введите ключ активации.
5. Дождитесь надписи «injected» — после неё лоадер закроется сам. Не запускайте его повторно поверх работающего.
6. Вытащите флешку и перейдите на сайт радара — адрес показывает лоадер.
7. Запустите Rust и зайдите на сервер.
8. Откройте консоль клавишей F1 и введите команду: `world.rendermap`\
   Клиент отрисует карту сервера и загрузит её на сайт радара.
9. Подождите несколько секунд, пока карта появится в браузере, и нажмите FOLLOW — камера будет следовать за вами.

{% hint style="info" %}
Совет: откройте сайт радара на телефоне или втором мониторе — карта не займёт игровой экран и не попадёт в захват стрима. Настройки переносятся между устройствами: Settings → «Publish my config», затем ввод 10-значного ID на втором устройстве.
{% endhint %}

КАК ПОЛЬЗОВАТЬСЯ РАДАРОМ

— Player — что показывать по игрокам: хотбар, ник, оружие, дистанция, ID команды,\
высота ▲/▼, стрелка взгляда; дальность отрисовки, размеры иконок и зум.\
Ниже — переключатели категорий: вы, живые игроки, слиперы, учёные.

— World — ресурсы, ящики, постройки, предметы, ловушки и транспорт; иконки вместо точек,\
подписи и дистанция, отдельная дальность отрисовки.

— Settings — язык RU/EN, прозрачность карты, сетка 150 м, заливка холста,\
RESET MAP (если карта не та или не загрузилась) и обмен конфигом по ID.

— Player List — живые игроки в радиусе по дистанции; клик по нику — камера следует за ним,\
при пропаже игрока возвращается к вам и снова переключается на него, когда он появится.

— Кнопки на карте: FOLLOW — следовать за вами, ON ME — разово центрировать,\
ROTATE — повернуть карту под вертикальный экран телефона, полноэкранный режим,\
сворачивание боковой панели.
