# Список функций

ИГРОКИ\
— Живые игроки, слиперы, учёные (NPC) и вы — четыре категории своими цветами, каждую можно выключить\
— Хотбар: шесть слотов пояса с иконками предметов\
— Ник игрока и оружие в руках\
— Дистанция до игрока\
— ID команды\
— Указатель высоты ▲/▼ — выше или ниже вас\
— Направление взгляда стрелкой, длина и толщина стрелки настраиваются\
— Дальность отрисовки игроков 50–500 м\
— Размер иконок пояса, точек игроков и шрифта — слайдерами\
— Зум карты от 1× до 30×

МИР\
— Название объекта и дистанция до него\
— Иконки вместо точек, размеры иконок и точек регулируются\
— Дальность отрисовки объектов 50–500 м\
— Ресурсы: сера, металл, HQM, камень, конопля\
— Ящики пяти типов: обычный, военный, элитный, с инструментами, таймерный\
— Постройки: шкафы, спальники, верстаки 1/2/3\
— Предметы в мире: выброшенные, трупы, рюкзаки\
— Ловушки: шотган-трап, автотурель, SAM-site, огнемётная турель, мина\
— Транспорт: миникоптер, скрап-хели, велосипед, мотоцикл, лошади, лодки

СПИСОК ИГРОКОВ\
— Все живые игроки в радиусе, отсортированы по дистанции\
— Клик по нику — камера следует за игроком\
— Автовозврат к вам, если игрок пропал, и снова к нему, когда появился

НАСТРОЙКИ\
— Интерфейс на русском и английском\
— Прозрачность карты\
— Сетка 150 м с настраиваемым цветом\
— Заливка холста без боковых полей\
— Сброс карты — повторная загрузка из игры\
— Экспорт и импорт настроек по 10-значному ID\
— Профиль на каждый браузер и его сброс

УПРАВЛЕНИЕ КАРТОЙ\
— FOLLOW — камера следует за вами\
— ON ME — разово центрировать карту на себе\
— ROTATE — вертикальная или горизонтальная ориентация для телефона\
— Полноэкранный режим\
— Сворачивание боковой панели — карта на всю ширину\
— В шапке: FPS, пинг, размер и сид карты, число игроков на сервере
