# Как запустить Monstr

## Текстовая инструкция

1. ➡️ Скачать IPA: Загрузите необходимый IPA-файл по ссылке которая была выдана после оплаты.
2. 📤 Открыть в GBox: Нажмите на загруженный файл -> Поделиться -> выберите GBox       (или импортируйте его вручную из вашего приложения "Файлы" внутри GBox).
3. ✍️ Подпишите приложение: Выберите IPA-файл в GBox и нажмите Подписать и установить.
4. ✅ Подтвердите: убедитесь, что выбран импортированный активный сертификат, затем продолжайте установку.
