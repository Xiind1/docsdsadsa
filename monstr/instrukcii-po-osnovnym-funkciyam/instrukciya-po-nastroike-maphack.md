# Инструкция по настройке MapHack

1. Включите функцию «Enable ESP».
2. Включите функцию «minimap radar» (радар на мини-карте).
3. С помощью ползунков Pos X, Pos Y и Size отрегулируйте контур MapHack (серый) так, чтобы он совпадал с мини-картой.

⚪️Если всё сделано правильно, враги будут отображаться корректно.
