# Как настроить авто-комбо

1. Включите функцию «enable esp».
2. Включите функцию «auto combo».
3. Перетащите кнопки авто-комбо в соответствии с их расположением на навыках, например: S1 — на первый навык...
4. Откройте меню чита, нажмите кнопку «Rec combo», закройте меню.
5. Нажимая на навыки, задайте правильную комбинацию для выбранного персонажа, например для Альфы: 3-1-2.
6. Откройте меню и нажмите «Stop + Save».
7. После этого отключите функцию «Edit skill markers» — она находится в самом низу вкладки «combo».

⚪️После этого вам нужно будет только нажимать кнопку «combo», чтобы ранее записанная комбинация навыков срабатывала по врагу.

⚪️Вы также можете уменьшить задержку перед использованием каждого навыка, перемещая ползунки, где указано время в миллисекундах, чтобы комбинация срабатывала быстрее.

⚠️ Обратите внимание: если анимация навыка длиннее указанной вами задержки, комбо не будет работать корректно.
