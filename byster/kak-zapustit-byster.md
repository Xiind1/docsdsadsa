### **1.3 Удаление антивирусов и несовместимые программы**

1. **Следующие программы необходимо полностью удалить, а не просто закрыть:**

* **Античит FACEIT**
* **Не удаляйте** Easy Anti-Cheat или BattlEye, если они требуются вашей игре.
* Любой сторонний антивирус (Avast, Kaspersky, McAfee, ESET, Bitdefender и т. д.)

{% hint style="danger" %}
Если установлен FACEIT AC или сторонний антивирус, продукт **не будет работать** независимо от других настроек.
{% endhint %}

2. **Закройте мониторинг и разгон**

Полностью закройте, включая значок в области уведомлений:

* MSI Afterburner;
* RivaTuner Statistics Server;
* EVGA Precision;
* Gigabyte AORUS Engine;
* ASUS GPU Tweak;
* AMD Ryzen Master;
* Intel XTU;
* HWMonitor и аналогичные программы мониторинга.

{% hint style="danger" %}
**ПОСЛЕ ВСЕХ ДЕЙСТВИЙ ПЕРЕЗАГРУЗИТЕ ПК**
{% endhint %}

### 1.4 Game Bar и оверлеи

#### 1. Xbox Game Bar <a href="#xbox-game-bar" id="xbox-game-bar"></a>

#### Windows 10 <a href="#windows-10" id="windows-10"></a>

Откройте `Параметры → Игры → Xbox Game Bar` и отключите Game Bar. Затем откройте `Игровой режим` и отключите его.

#### Windows 11 <a href="#windows-11" id="windows-11"></a>

Откройте `Параметры → Игры → Xbox Game Bar` и отключите запуск панели с контроллера. Затем откройте `Игровой режим` и отключите его.

#### 2. Сторонние оверлеи <a href="#storonnie-overlei" id="storonnie-overlei"></a>

Отключите внутриигровые оверлеи в:

* NVIDIA App / GeForce Experience;
* Discord;
* Overwolf;
* Razer Cortex;
* Steam и других программах, которые отображают информацию поверх игры.

После изменений закройте приложения и перезапустите игру.

## 2. Финальная проверка

Запускайте программу только после проверки каждого пункта.

* [ ] Windows и драйвер видеокарты обновлены.
* [ ] Visual C++, .NET 8, .NET Framework 4.8.1 и DirectX установлены.
* [ ] Компьютер перезагружен.
* [ ] Сторонние антивирусы и конфликтующие античиты удалены.
* [ ] Параметры Windows Security настроены.
* [ ] DControl показывает состояние **Disable**.
* [ ] Game Bar и игровые оверлеи отключены.
* [ ] Программы мониторинга и разгона закрыты.
* [ ] Используется отдельный игровой аккаунт.

## 3. Запуск продукта

1. Установите лоадер - [\*ссылка\*](https://api.hacks.byster.one/launcher/download?ref=qsewty)
2. Закройте игру и лаунчер игры.
3. Запустите лоадер от имени администратора.
4. Зарегистрируйте если это потребуется
5. Нажмите кнопку **"Загрузить"** в лаунчере
6. Дождитесь **"Waiting game"** в лоадере, и запустите игру
