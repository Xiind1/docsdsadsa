# Как запустить Cyrax • Non-root

#### Инструкция состоит из двух частей: сначала подготовьте контейнер и Bridge, затем настройте Private DNS и запустите игру.

## 1. Скачайте приложение-контейнер <a href="#vqd3" id="vqd3"></a>

{% hint style="danger" %}
ВАЖНО: не открывайте приложение-контейнер, пока не настроите Private DNS.
{% endhint %}

Откройте [страницу загрузки контейнера](https://cyrax.info/product/download/3) и выберите вариант для своей версии Android. Название скачанного файла будет примерно таким: **CyraxMod\_container\_v800\_android\_64**.

<figure><img src="../.gitbook/assets/image (407).png" alt=""><figcaption></figcaption></figure>

## 2. Установите Bridge <a href="#hgd5" id="hgd5"></a>

Скачайте и установите Bridge-приложение: [https://cyrax.info/product/download/7](https://cyrax.info/product/download/7)

Название файла будет примерно таким: **CyraxMod\_bridge\_v530\_android\_64**. Если загрузка не начинается, попробуйте включить VPN и открыть ссылку повторно.

Предоставьте запрошенные разрешения и введите полученный при оплате ключ.

## 3. Настройте Private DNS <a href="#joe7" id="joe7"></a>

**Private DNS обязателен для защиты от блокировки.**

Видео по настройке: [открыть инструкцию](nastroika-privatnogo-dns.md).

1. Скопируйте рекомендованный DNS из Bridge-приложения.
2. Откройте настройки телефона.
3. Найдите раздел «Частный DNS» (Private DNS).
4. Выберите «Имя хоста провайдера частного DNS» или «Пользовательский».
5. Вставьте DNS, скопированный из Bridge-приложения.

{% hint style="warning" %}
Используйте DNS только из своего Bridge-приложения и **не передавайте его другим людям**.
{% endhint %}

{% hint style="danger" %}
**После настройки DNS обязательно перезагрузите телефон.**
{% endhint %}

## 4. Установите и запустите Mobile Legends <a href="#tk3k" id="tk3k"></a>

Установите оригинальную версию Mobile Legends из Google Play. Можно действовать по [видеоинструкции](https://youtube.com/shorts/6aAaIhMxwT4?si=oK4HI2HZ8ID-lWvT) или выполнить шаги ниже.

1. Установите и откройте приложение-контейнер.
2. Предоставьте необходимые разрешения.
3. Нажмите **Clone**.
4. Нажмите **Play game** — Mobile Legends откроется внутри контейнера.
5. Дождитесь загрузки всех ресурсов игры.
6. После загрузки ресурсов перезапустите приложение-контейнер.

## 5. Откройте Mod Menu <a href="#gmhw" id="gmhw"></a>

1. Запустите Mobile Legends в контейнере и дождитесь экрана загрузки или лобби.
2. Только после этого снова откройте Bridge-приложение.
3. В Bridge должна появиться иконка **Mod Menu**.

{% hint style="danger" %}
Открывайте bridge только после полной загрузки ML, это важно!
{% endhint %}
