# Как запустить Cyrax • Root

{% hint style="info" %}
Только для устройств с root-доступом.\
Только для опытных пользователей.\
Если у вас нет root-доступа, или вы даже не знаете, что такое root, или не умеете настраивать root-модули, то пропустите эту инструкцию и используйте Non-Root, потому что я не даю инструкций по настройке root!
{% endhint %}

## 2. Установка модулей

1. Скачайте модуль Cyrax Zygisk - [ссылка](https://cyrax.info/product/download/4)
2. Скачайте модуль ZygiskNext - [ссылка](https://github.com/Dr-TSNG/ZygiskNext/releases/download/v1.3.2/Zygisk-Next-1.3.2-688-2c60cdd-release.zip)&#x20;
3. Откройте приложение Magisk или KernelSU
4. Установите модули Cyrax и ZygiskNext

* В Magisk необходимо отключить стандартный Zygisk в настройках и перезагрузить телефон
* В KernelSU достаточно просто перезагрузить телефон

## 3. Запуск Cyrax

### Текстовая инструкция

1. Установите Mobile Legends и скачайте полный набор ресурсов
2. Скачайте, установите и запустите приложение Bridge (оно уже обязано у вас быть так как через него ставится DNS в 1 пункте)
3. Предоставьте необходимые разрешения, когда появится запрос
4. Введите ключ для входа
5. Вернитесь в Mobile Legends
6. Теперь вы должны увидеть значок меню модификаций
