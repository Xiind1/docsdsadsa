# Настройка приватного DNS

## Текстовая инструкция

#### Установите Bridge - [ссылка](https://cyrax.info/product/download/7)

1. Скопируйте рекомендуемый DNS из приложения Bridge
2. Перейдите в настройки телефона
3. Найдите "Частный DNS"
4. Установите значение "Имя хоста провайдера частного DNS" или "Пользовательский"
5. Вставьте DNS скопированный из приложения

{% hint style="danger" %}
ПЕРЕЗАГРУЗИТЕ ТЕЛЕФОН ПОСЛЕ УСТАНОВКИ DNS
{% endhint %}

{% hint style="warning" %}
Никому не передавайте свой приватный DNS.
{% endhint %}
