### ШАГ 1. Подготовка системы к первому запуску

1. **Отключение Безопасность Windows**

* Перейдите в параметры системы (вы можете нажать комбинацию WIN + I)
* Откройте **Безопасность Windows**
* Отключите параметр **"Защита в реальном времени"**

<figure><img src="../.gitbook/assets/image (140).png" alt=""><figcaption></figcaption></figure>

2. **Окончательно отключите Безопасность Windows с помощью программы dControl**

* **Google Drive** - [ссылка для загрузки](https://drive.google.com/file/d/19G3C5Gg1KDr1W05jhwwB6xeMx8PG_IrU/view?usp=sharing) (пароль 1234)
* **Yandex Disk** - [ссылка для загрузки](https://disk.yandex.ru/d/pLPzChHbwskWNQ) (пароль 1234)
* **Mega** - [ссылка для загрузки](https://mega.nz/file/Vr9EUSKB#Sn0bze9l49paasaCZqYPkAodQwo5avSpUWVzo5f4x38)

<figure><img src="../.gitbook/assets/image (141).png" alt=""><figcaption><p><strong>Нажмите "</strong><mark style="color:red;"><strong>Отключить Защитник Windows</strong></mark><strong>"</strong> </p></figcaption></figure>

3. **Отключите изоляцию ядра.**

* Параметры => Обновление и безопасность => Безопасность Windows => Безопасность устройства => Сведения об изоляции ядра

<figure><img src="../.gitbook/assets/image (245).png" alt=""><figcaption></figcaption></figure>

4. **Отключите «Защиту на основе репутации»**

* Параметры => Обновление и безопасность => Безопасность Windows => Управление приложениями/браузером => Параметры защиты на основе репутации

<figure><img src="../.gitbook/assets/image (246).png" alt=""><figcaption></figcaption></figure>

5. **Удаление конфликтующего программного обеспечения**

Следующие программы необходимо **полностью удалить**, а не просто закрыть:

* **Античит FACEIT**
* Любой сторонний антивирус (Avast, Kaspersky, McAfee, ESET, Bitdefender и т. д.)

{% hint style="danger" %}
Если установлен FACEIT AC или сторонний антивирус, продукт **не будет работать** независимо от других настроек.
{% endhint %}

### Шаг 2. Скачать лоадер

Прямая ссылка на актуальный лоадер:

* [tndr-panel.online/loader/tundra\_radar.exe](https://tndr-panel.online/loader/tundra_radar.exe)

**Важно:** сначала выполните подготовку выше и только потом скачивайте файл — иначе антивирус удалит его на этапе загрузки, и вы получите пустую папку.

### Шаг 3. Запустить и активировать

1. Правой кнопкой по .exe → **«Запуск от имени администратора»**.
2. Вставьте **ключ активации** из письма после оплаты. Если клавиатура не работает в поле ввода — используйте вставку из буфера обмена (Ctrl+V).
3. Дождитесь строки статуса вроде _«Connected»_ / _«Waiting for game»_. Окно лоадера закроется само, и в системном браузере откроется ссылка на радар — это ожидаемое поведение.

### Шаг 4. Зайти в игру

1. Запустите игру обычным способом — через лаунчер или Steam.
2. Выберите карту, режим и дождитесь загрузки локации.
3. Как только персонаж окажется в рейде/катке — на веб-карте сами появятся игроки, лут, боссы, гранаты и тд. **В главном меню и на загрузочном экране карта пустая — это нормально.**
4. Держите вкладку радара **открытой весь рейд**.

Для следующего рейда/катки ничего перезапускать не нужно — новая карта подхватится автоматически.

### Открыть радар на телефоне или втором экране

Скопируйте ссылку, которая открылась в браузере, и откройте её на смартфоне, планшете или втором мониторе. Интерфейс адаптивный — портретная и альбомная раскладка. Это удобнее по двум причинам:

* карта не попадает в захват OBS/стрима;
* основной монитор не забит вторым окном.

Ссылка одна и та же — то же приложение отображается сразу на всех устройствах, где вы её открыли, и обновляется в реальном времени.
