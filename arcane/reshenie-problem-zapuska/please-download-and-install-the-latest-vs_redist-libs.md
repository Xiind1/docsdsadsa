# Please download and install the latest vs\_redist libs

<img src="../../.gitbook/assets/unknown (20).png" alt="" height="150" width="384">

* **Установите последнюю версию библиотек:** [**\*ссылка\***](https://drive.google.com/file/d/1-MAtvixkw43959-WtNi-VQU_weMeZsc-/view?usp=sharing)



* **Если установка последних версий библиотек не помогла, следуйте инструкции ниже.**\
  \- Перейдите в диспетчер задач и закройте все процессы связанные с приложением AMD\
  (Завершите задачи AMD Radeon, AMDSrv..,  AMDow, CPUMetrics и все остальные)\
  \- Перейдите в папку куда установлена программа AMD Software: Adrenaline Edition\
  Стандартная папка (C:\Program Files\AMD\CNext\CNext)\
  \- [Скачайте и разархивируйте файл Libs.rar.](https://disk.yandex.ru/d/DdrlIgbNXXp2Mg) затем скопируйте и замените все файлы DLL в папке AMD Software (CNext/CNext)\
  \- Если вы не можете скопировать файлы DLL в эту папку AMD («файл открыт в другой программе»), это означает, что процессы AMD все еще запущены. Дважды проверьте, закрыли ли вы все процессы AMD и Radeon в диспетчере процессов.\
  \- После замены всех файлов, вы можете повторно запустить программу AMD Software, обязательно нужно включить отображение показателей производительности.\
  \- Теперь можно вернуться к запуску софта.
