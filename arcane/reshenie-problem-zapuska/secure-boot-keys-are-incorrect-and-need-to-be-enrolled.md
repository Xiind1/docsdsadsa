# Secure boot keys are incorrect and need to be enrolled

Чтобы исправить эту ошибку, войдите в BIOS и включите Secure Boot, сохраните настройки, убедитесь, что вы включили его правильно, открыв PowerShell и набрав "Confirm-SecureBootUEFI", если результат "True", вы можете перезагрузить компьютер, затем войдите в BIOS и отключите Secure Boot.
