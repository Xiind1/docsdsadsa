## **1. Подготовка системы к запуску продукта**&#x20;

#### **1. Отключение Безопасности Windows**

* Перейдите в параметры системы (вы можете нажать комбинацию WIN + I)
* Откройте **Безопасность Windows**
* Отключите параметр **"Защита в реальном времени" и остальные параметры защиты**

<figure><img src="../.gitbook/assets/image (140).png" alt=""><figcaption></figcaption></figure>

2. **Окончательно отключите Безопасность Windows с помощью программы dControl**

* **Google Drive** - [ссылка для загрузки](https://drive.google.com/file/d/19G3C5Gg1KDr1W05jhwwB6xeMx8PG_IrU/view?usp=sharing) (пароль 1234)
* **Yandex Disk** - [ссылка для загрузки](https://disk.yandex.ru/d/pLPzChHbwskWNQ) (пароль 1234)
* **Mega** - [ссылка для загрузки](https://mega.nz/file/Vr9EUSKB#Sn0bze9l49paasaCZqYPkAodQwo5avSpUWVzo5f4x38)

<figure><img src="../.gitbook/assets/image (141).png" alt=""><figcaption><p><strong>Нажмите "</strong><mark style="color:red;"><strong>Отключить Защитник Windows</strong></mark><strong>"</strong> </p></figcaption></figure>

3. **Отключите изоляцию ядра.**

* Параметры => Обновление и безопасность => Безопасность Windows => Безопасность устройства => Сведения об изоляции ядра

<figure><img src="../.gitbook/assets/image (245).png" alt=""><figcaption></figcaption></figure>

4. **Отключите «Защиту на основе репутации»**

* Параметры => Обновление и безопасность => Безопасность Windows => Управление приложениями/браузером => Параметры защиты на основе репутации

<figure><img src="../.gitbook/assets/image (246).png" alt=""><figcaption></figcaption></figure>

5. **Удаление конфликтующего программного обеспечения**

Следующие программы необходимо **полностью удалить**, а не просто закрыть:

* **Античит FACEIT**
* Любой сторонний антивирус (Avast, Kaspersky, McAfee, ESET, Bitdefender и т. д.)

{% hint style="danger" %}
Если установлен FACEIT AC или сторонний антивирус, продукт **не будет работать** независимо от других настроек.
{% endhint %}

{% hint style="danger" %}
**ПОСЛЕ ВСЕХ ДЕЙСТВИЙ ПЕРЕЗАГРУЗИТЕ ПК**

## 2. Установка оверлея для отображения Arcane

{% hint style="info" %}
Работа проекта "_**Arcane**_" основана на продуктах, типа "**External**", в связи с чем проект использует оверлей Вашей видеокарты для отображения продукта в самой игре.
{% endhint %}

### **Если ваша игра** ROB RUN вам нужен оверлей Discord или Medal

{% hint style="info" %}
Вам нужен только 1 оверлей на ваш выбор, не нужно устанавливать сразу оба
{% endhint %}

#### **1. Настройка Discord оверлея**

* Включите оверлей и отключите устаревший оверлей.

<figure><img src="../.gitbook/assets/image (412).png" alt=""><figcaption></figcaption></figure>

*   Включите аппаратное ускорение<br>

    <figure><img src="../.gitbook/assets/image (413).png" alt=""><figcaption></figcaption></figure>
* Убедитесь, что вы не отключили наложение для конкретной игры.

#### **2. Medal оверлей**

Для использования необходимо просто скачать оверлей и зарегистрироваться.

### Если у вас другая игра, вам нужен оверлей Nvidia или Amd

1. **Если у вас видеокарта Nvidia:**\
   \- Устанавливаем NVIDIA App\
   \- Выполняем авторизацию\
   \- Устанавливаем последнюю версию видео драйвера\
   \- Включаем Nvidia оверлей
2. **Если у вас видеокарта AMD:**\
   \- Устанавливаем AMD Software: Adrenalin Edition (PRO не работает)\
   \- Устанавливаем последнюю версию видео драйвера\
   \- Активируем в настройках внутриигровой оверлей\
   \- Во вкладке производительность, включаем отображение производительности

## **3. Запуск Arcane**

1. **Скачать лоадер по одной из ссылок ниже.** [<br>](https://storage.e-arcane.com/LoaderArcane.zip)1: [https://mega.nz/folder/SFEijIYB#ItpPdnVINK3H-rQXK6DJjw<br>](https://mega.nz/folder/SFEijIYB#ItpPdnVINK3H-rQXK6DJjw)2: [https://disk.yandex.ru/d/68JncC0ROmFEzA](https://disk.yandex.ru/d/68JncC0ROmFEzA)&#x20;
2. Создайте папку для лоалдера пример названия - "arc"
3. Запустить файл софта от имени администратора.
4. Дождитесь обновления лоадера и запустите его снова.
5. Введите ваш ключ и нажмите "Enter" (Чтобы ввести ключ в лоадер, после его копирования, используйте правую кнопку мыши в CMD лоадере)
6. Лоадер автоматически закроется после успешной загрузки
7. Запустить игру.
8. Меню появится автоматически.\
   Открыть / Закрыть меню можно клавишей "**Home или Insert**"\
   Для PUBG меню на Insert, и вы можете увидеть его только в матче (в лобби меню невидимо). Также управление в меню осуществляется с помощью клавиш со стрелками.\
   Для выгрузки софта используйте клавишу "END"&#x20;

{% hint style="warning" %}
Если у вас возникла какая либо ошибка во время запуска, решение можно найти [здесь](reshenie-problem-zapuska/)
{% endhint %}
