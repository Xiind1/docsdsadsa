# Permanent Unlocker

1. **Legacy Injector**&#x20;

Legacy Prestige был одноразовый награда для определенных игроков Dead by Daylight. Только те игроки, которые владели игрой до релиза Хэллоуина в октябре 2016 года имеют право на получение Legacy Prestige.&#x20;

Legacy Prestige был специальной наградой для тех игроков, которые достигли 50-го уровня Prestige III со своими персонажами до выхода главы, посвященной Хэллоуину.

2. **Prestige Injector**

Prestige Injector - повышает урвоень вашего престижа использя Bloodpoints, но тратя при этом намного меньше поинтов, чем потребовалось бы для самостоятельной прокачки престижа

2 миллиона поинтов = 100 престиж (больше, если использовать поиск предметов)

3. **Cosmetics Injector**

Cosmetics Injector - позволяет выдавать любые косметические предметы персонажам
