## **1. Подготовка системы к запуску продукта**&#x20;

### **1.2 Отключение Безопасности Windows**

1. **Отключение защиты в реальном времени**

* Перейдите в параметры системы (вы можете нажать комбинацию WIN + I)
* Откройте **Безопасность Windows**
* Отключите параметр **"Защита в реальном времени" и остальные параметры защиты**

<figure><img src="../../.gitbook/assets/image (140).png" alt=""><figcaption></figcaption></figure>

2. **Окончательно отключите Безопасность Windows с помощью программы dControl**

* **Google Drive** - [ссылка для загрузки](https://drive.google.com/file/d/19G3C5Gg1KDr1W05jhwwB6xeMx8PG_IrU/view?usp=sharing) (пароль 1234)
* **Yandex Disk** - [ссылка для загрузки](https://disk.yandex.ru/d/pLPzChHbwskWNQ) (пароль 1234)
* **Mega** - [ссылка для загрузки](https://mega.nz/file/Vr9EUSKB#Sn0bze9l49paasaCZqYPkAodQwo5avSpUWVzo5f4x38)

<figure><img src="../../.gitbook/assets/image (141).png" alt=""><figcaption><p><strong>Нажмите "</strong><mark style="color:red;"><strong>Отключить Защитник Windows</strong></mark><strong>"</strong> </p></figcaption></figure>

3. **Отключите изоляцию ядра.**

* Параметры => Обновление и безопасность => Безопасность Windows => Безопасность устройства => Сведения об изоляции ядра

<figure><img src="../../.gitbook/assets/image (245).png" alt=""><figcaption></figcaption></figure>

4. **Отключите «Защиту на основе репутации»**

* Параметры => Обновление и безопасность => Безопасность Windows => Управление приложениями/браузером => Параметры защиты на основе репутации

<figure><img src="../../.gitbook/assets/image (246).png" alt=""><figcaption></figcaption></figure>

### **1.3 Удаление антивирусов и несовместимые программы**

1. **Следующие программы необходимо полностью удалить, а не просто закрыть:**

* **Античит FACEIT**
* Любой сторонний антивирус (Avast, Kaspersky, McAfee, ESET, Bitdefender и т. д.)

{% hint style="danger" %}
Если установлен FACEIT AC или сторонний антивирус, продукт **не будет работать** независимо от других настроек.
{% endhint %}

{% hint style="danger" %}
**ПОСЛЕ ВСЕХ ДЕЙСТВИЙ ПЕРЕЗАГРУЗИТЕ ПК**
{% endhint %}

## 2. Активация ключа и установака лаунчера

1. Ключ активируется на официальном сайте Nyxia в личном кабинете

{% hint style="info" %}
FunPay запретил давать ссылки на сторонние сайты, поэтому ссылку дать не смогу
{% endhint %}

2. Введите ключ который вы получили после оплаты в разделе "My Licenses"

<figure><img src="../../.gitbook/assets/image (296).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../../.gitbook/assets/image (297).png" alt=""><figcaption></figcaption></figure>

3. Утановите лаунчер

<figure><img src="../../.gitbook/assets/image (298).png" alt=""><figcaption></figcaption></figure>

4. Извлеките папку "Launcher" из архива на рабочий стол или в любое другое место

## 3. Запуск Nyxia

1. Запустите **NyxiaUnlocker.exe** и войдите в свою учетную запись

<figure><img src="../../.gitbook/assets/image (300).png" alt=""><figcaption></figcaption></figure>

2. Выберите версию анлокера которая вам подходит **Permanent / Temporary**

<figure><img src="../../.gitbook/assets/image (301).png" alt=""><figcaption></figcaption></figure>
