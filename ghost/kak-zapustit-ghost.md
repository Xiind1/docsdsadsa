## **1. Подготовка системы к запуску продукта**

### **1.1 Удаление конфликтующего программного обеспечения**

Следующие программы необходимо **полностью удалить**, а не просто закрыть:

* **Античит FACEIT**
* Любой сторонний антивирус (Avast, Kaspersky, McAfee, ESET, Bitdefender и т. д.)

{% hint style="danger" %}
Если установлен FACEIT AC или сторонний антивирус, продукт **не будет работать** независимо от других настроек.
{% endhint %}

{% hint style="danger" %}
**ПОСЛЕ УДАЛЕНИЯ ПЕРЕЗАГРУЗИТЕ ПК**
{% endhint %}

### **1.2 Отключение Безопасности Windows**

* Перейдите в параметры системы (вы можете нажать комбинацию WIN + I)
* Откройте **Безопасность Windows**
* Отключите параметр **"Защита в реальном времени"**

<figure><img src="../.gitbook/assets/image (140).png" alt=""><figcaption></figcaption></figure>

2. **Окончательно отключите Безопасность Windows с помощью программы dControl**

* **Google Drive** - [ссылка для загрузки](https://drive.google.com/file/d/19G3C5Gg1KDr1W05jhwwB6xeMx8PG_IrU/view?usp=sharing) (пароль 1234)
* **Yandex Disk** - [ссылка для загрузки](https://disk.yandex.ru/d/pLPzChHbwskWNQ) (пароль 1234)
* **Mega** - [ссылка для загрузки](https://mega.nz/file/Vr9EUSKB#Sn0bze9l49paasaCZqYPkAodQwo5avSpUWVzo5f4x38)

<figure><img src="../.gitbook/assets/image (141).png" alt=""><figcaption><p><strong>Нажмите "</strong><mark style="color:red;"><strong>Отключить Защитник Windows</strong></mark><strong>"</strong> </p></figcaption></figure>

### **1.3 Отключение параметров защиты на основе репутации**

Перейдите:\
Параметры → Обновление и безопасность → Безопасность Windows → Управление приложениями и браузером → Защита на основе репутации → Отключить все параметры.

2. Откройте сайт: [https://ghost.download/](https://ghost.download/)
3. Вставьте полученный ключ в поле и нажмите Activate NOW.

## 3. Запуск продукта

* Появится небольшое прозрачное окно загрузкой продукта.

<img src="../.gitbook/assets/unknown (13).png" alt="" height="343" width="602">

{% hint style="info" %}
Если окно с надписью  Wait for the software to download, висит более двух минут, либо же закрылось, откройте loader повторно
{% endhint %}

*   После успешного инжекта ,в окне будет сообщение, что вы можете открывать игру.<br>

    <img src="../.gitbook/assets/unknown (14).png" alt="" height="325" width="602">



* Меню чита появится после окончательного инжекта уже в самой игре.

<img src="../.gitbook/assets/unknown (15).png" alt="" height="455" width="602">

{% hint style="info" %}
По стандарту меню открывается на INSERT
{% endhint %}
