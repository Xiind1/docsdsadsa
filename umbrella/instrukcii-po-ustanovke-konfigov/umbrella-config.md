
2. Перейдите во вкладку Cloud

3. Нажмите на кнопку "Add by Code"

## ( Dodger + Radiuses + FailSwitch ) Settings

1. Установите конфиг - [ссылка](https://e.pcloud.link/publink/show?code=XZf3kGZthkzfL5edyutLCu25MrlHbHVbWC7)
2. Закройте игру и закиньте этот файл в папку с лаунчером ( C:\Umbrella )

{% hint style="warning" %}
Этот файл хранит настройки доджера и радиусов, Обязательно сохраните свой db.json , дабы не потерять все свои настройки, возможно они вам не подойдут.
{% endhint %}

***

{% hint style="info" %}
* Бинды на комбо? → Их нет, забиндите вручную на удобную для вас клавишу.
* Нет настроек комбо на некоторых героях? → Их нет, потому что там настройки ограничиваются включением и биндами.
{% endhint %}
