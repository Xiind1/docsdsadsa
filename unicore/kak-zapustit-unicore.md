### 2. Подготовка системы к первому запуску

1. **Отключение Безопасность Windows**

* Перейдите в параметры системы (вы можете нажать комбинацию WIN + I)
* Откройте **Безопасность Windows**
* Отключите параметр **"Защита в реальном времени"**

<figure><img src="../.gitbook/assets/image (140).png" alt=""><figcaption></figcaption></figure>

2. Окончательно отключите **Безопасность Windows** с помощью программы **dControl**

* **Google Drive** - [ссылка для загрузки](https://drive.google.com/file/d/19G3C5Gg1KDr1W05jhwwB6xeMx8PG_IrU/view?usp=sharing) (пароль 1234)
* **Yandex Disk** - [ссылка для загрузки](https://disk.yandex.ru/d/pLPzChHbwskWNQ) (пароль 1234)
* **Mega** - [ссылка для загрузки](https://mega.nz/file/Vr9EUSKB#Sn0bze9l49paasaCZqYPkAodQwo5avSpUWVzo5f4x38)

<figure><img src="../.gitbook/assets/image (141).png" alt=""><figcaption><p><strong>Нажмите "</strong><mark style="color:red;"><strong>Отключить Защитник Windows</strong></mark><strong>"</strong> </p></figcaption></figure>

{% hint style="warning" %}
Если ваш браузер блокирует загрузку, решение можно найти [здесь](reshenie-problem-zapuska/brauzer-blokiruet-zagruzku-faila.md)
{% endhint %}

5. **Удаление конфликтующего программного обеспечения**

Следующие программы необходимо **полностью удалить**, а не просто закрыть:

* **Античит FACEIT**
* Любой сторонний антивирус (Avast, Kaspersky, McAfee, ESET, Bitdefender и т. д.)

{% hint style="danger" %}
Если установлен FACEIT AC или сторонний антивирус, продукт **не будет работать** независимо от других настроек.
{% endhint %}

6. Отключение оверлеев

* Закройте все оверлеи которые появляются при запуске игры (например Riva, Discord, FPS, Action, Bandicam и прочие) Исключение: Оверлей Nvidia, Epic Games

{% hint style="danger" %}
**ПОСЛЕ ВСЕХ ДЕЙСТВИЙ ПЕРЕЗАГРУЗИТЕ ПК**
{% endhint %}

### 3. Если ваша игра Genshin Impact

Включите **Виртуализацию** в **BIOS**

1. <mark style="color:red;">**VT-X (VT-D)**</mark> - Если у вас процессор Intel
2. <mark style="color:red;">**SVM Mode**</mark> - Если у вас процессор от Amd&#x20;

Можно проверить включена ли по следующему пути: Диспетчер Задач -> ЦП -> Процессор

<figure><img src="../.gitbook/assets/image (216).png" alt=""><figcaption></figcaption></figure>

### 4. Регистрация аккаунта и  установка лаунчера

1. Зарегистрируйте аккаунт в [панели управления](https://dash.unicore.cloud/login/)

<figure><img src="../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure>

2. Используйте кнопку <mark style="color:blue;">«Добавить ключ»</mark> для активации вашего ключа.

<figure><img src="../.gitbook/assets/image (33).png" alt=""><figcaption></figcaption></figure>

3. После активации ключа установите лаунчер нажав на кнопку <mark style="color:blue;">«Скачать»</mark>

<figure><img src="../.gitbook/assets/image (34).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
Если ваш браузер блокирует загрузку, решение можно найти [здесь](reshenie-problem-zapuska/brauzer-blokiruet-zagruzku-faila.md)
{% endhint %}

4. Откройте лаунчер.

{% hint style="warning" %}
Если лоадер не появился при запуске, но его процесс есть в диспетчере задач используйте VPN
{% endhint %}

### 5. Процесс запуска

1. Для запуска продукта выберите вашу игру и нажмите <mark style="color:blue;">«launch»</mark>

<figure><img src="../.gitbook/assets/image (36).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
Если после нажатия кнопки **launch** у вас возникла ошибка, решение можно найти [здесь](reshenie-problem-zapuska/)
{% endhint %}

2. Подождите когда закончится загрузка и лаунчер закроется.
3. Запустите игру.

{% hint style="danger" %}
**Перед запуском игры убедитесь, что она соответствует указанным ниже настройкам.**

* «Wuthering Waves»\
  В ланучере игры включите параметр **"Launch with DirectX 11"** .
* «Arknights: Endfield»\
  В ланучере игры включите параметр **"Launch with DirectX 11"**&#x20;
* «Neverness to Everness»\
  В ланучере игры включите параметр **"Launch with DirectX 11"**
* «Duet Night Abyss»\
  Переименуйте папку **StreamlineCore** \
  Она распологается по адресу **DuetNightAbyss\DNA Game\Engine\Plugins\Nvidia.** \
  Пример: **StreamlineCore123**
{% endhint %}

4. На этапе выбора сервера нажмите <mark style="color:red;">**F2**</mark> или <mark style="color:$danger;">**FN + F2**</mark>

{% hint style="warning" %}
Если после нажатия кнопки **F2** у вас перезагружается ПК или не появляется меню, решение можно найти [здесь](reshenie-problem-zapuska/)
{% endhint %}
