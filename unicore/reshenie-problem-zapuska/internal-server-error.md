# "Internal server error"

{% embed url="https://www.youtube.com/watch?ab_channel=UnicoreCloud&v=f9aonP7ufFk" %}

<figure><img src="../../.gitbook/assets/image (17) (1).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Чаще всего это глобальная ошибка, когда наш сервер не работает. Пожалуйста воспользуйтесь этой видео-инструкцией для смены сервера.
{% endhint %}

1. Создайте ярлык загрузчика
2. Откройте свойства ярылка и введите команду "--diagnostic"

<figure><img src="../../.gitbook/assets/image (18) (1).png" alt=""><figcaption></figcaption></figure>

3. Откройте ярлык с сохраненным измененным параметром запуска
4. Выберите сервер и попробуйте снова

<figure><img src="../../.gitbook/assets/image (19) (1).png" alt=""><figcaption></figcaption></figure>
