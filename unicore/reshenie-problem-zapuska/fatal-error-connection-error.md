# "FATAL ERROR! Connection error"

<figure><img src="../../.gitbook/assets/image (12) (1).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Проблема возникает, если все 8 серверов не смогли обработать запрос или если у пользователя не включена синхронизация времени в Windows.
{% endhint %}

1. Откройте настройку "Даты и времени"

<figure><img src="../../.gitbook/assets/image (13) (1).png" alt=""><figcaption></figcaption></figure>

2. Нажмите кнопку "Синхронизировать"

<figure><img src="../../.gitbook/assets/image (14) (1).png" alt=""><figcaption><p><strong>Синхронизация часов</strong></p></figcaption></figure>

{% hint style="danger" %}
В случае если проблема осталась после синхронизации времени - пожалуйста попробуйте подключить VPN сервис. Возможно что ваше интернет соединение блокирует наш сервер.
{% endhint %}
