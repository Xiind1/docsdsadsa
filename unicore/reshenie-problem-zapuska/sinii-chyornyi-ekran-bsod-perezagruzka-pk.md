# "Синий/Чёрный экран (BSOD) Перезагрузка пк"

<figure><img src="https://2582495776-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FLdxCokJEnpQ3wG4zbVLX%2Fuploads%2FJd4ZsEgpX1JSUhs54TIX%2Fimage.png?alt=media&#x26;token=db91be32-4daa-48a9-9e0b-9f73afdb9674" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Основным фактором является сбой при инициализации драйвера. В большистве случаев это вызвано конфликтом с защитным ПО или активными функциями безопасности
{% endhint %}

1. Просканируйте ваш компьютер с помощью утилиты - [https://antivirus-removal-tool.com/](https://antivirus-removal-tool.com/) и удалите антивирусное ПО: «Kaspersky» / «Avast» / «Avira» / «360 total secure» и т.д. Вам необходимо полностью удалить антивирус, если у вас возникла эта проблема.
2. Полностью <mark style="color:red;">отключите / удалите</mark> любое игровое программное обеспечение, связанное с мышью / клавиатурой. «Razer Cortex, Razer Synapse, Corsair RGB control, Amroury Crate». В некоторых случаях, когда это помогало решить проблему.
3. Используйте сочатение клавиш Win + R и введите "msconfig".

<figure><img src="https://2582495776-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FLdxCokJEnpQ3wG4zbVLX%2Fuploads%2FADe0AT21aKPegMAeZ91V%2Fimage.png?alt=media&#x26;token=94b34fd6-d75f-471f-bed3-5461e16cb888" alt=""><figcaption></figcaption></figure>

4. Перейдите в раздел "Службы", далее нажмите "Не отображать службы Microsoft" и "Отключить все". Сделайте запуск после отключеня всех служб.
