# "2 звуковых сигнала при нажатии кнопки F2, краш игры."

{% hint style="info" %}
Наличие 2-х звуковых сигналов говорит о успешном запуске, последующий краш вызван конфликтом со сторонними модификациями (Reshade / Redux / Enb)
{% endhint %}

1. Удалите все модификации, **Reshade / Redux**
2. Переустановите игру если проблема не устранилась.
3. Вы можете запустить GTA:Online для проверки стабильности запуска.

{% hint style="danger" %}
Если после выполнения всех шагов вы все еще не можете запустить продукт - полностью переустановите игру и не устанавливайте никаких модификаций! Пожалуйста, попробуйте установить чистую версию игры.
{% endhint %}
