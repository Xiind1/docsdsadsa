# "Нет эффекта при нажатии F2"

{% hint style="info" %}
Чаще всего это происходит из-за наличия антивирусов: "Kaspersky" / "Avast" / "Dr.web" / Антивирусы — «Kaspersky», «Avast», «Dr.Web», «AntiMalwarebytes» и другое антивирусное ПО. Отключение антивирусов зачастую не помогает, так как приложение изолирует ядра системы при загрузке ПК.

Вам необходимо найти программу, которая выполнила эту изоляцию. Обратите внимание на все подозрительные запущенные процессы (программы), которые могут каким‑либо образом влиять на безопасность Windows.
{% endhint %}

1. Попробуйте свернуть игру и нажать **F2** на рабочем столе, если не помогло перейдите к следующему пункту.
2. Откройте параметры Изоляции Ядра Windows 10/11 (можно найти в папке "Безопасность устройства")

<figure><img src="../../.gitbook/assets/image (8) (1).png" alt=""><figcaption><p><strong>Изоляция</strong></p></figcaption></figure>

3. Отключите функцию "Целостности памяти" во вкладке "Изоляция Ядра"
4. Полностью удалите (отключение не сработает) любое сторонне антивирусное П.О:                 <mark style="color:red;">**"Kaspersky" / "Avast" / "Avira" / "360 total secure" / "Dr.Web" / "Avast"**</mark>
5. Перезагрузите ПК и попробуйте снова.
