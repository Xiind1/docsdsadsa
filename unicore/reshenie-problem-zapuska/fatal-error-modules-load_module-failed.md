# "FATAL ERROR! modules::load\_module failed"

<figure><img src="../../.gitbook/assets/image (16) (1).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Ошибка возникает в том случае если средства защиты / антивирус удаляют загрузчик и не позволяют ему загрузить файлы с сервера.
{% endhint %}

1. Полностью удалите (отключение не сработает) любое сторонне антивирусное П.О: «Kaspersky» / «Avast» / «Avira» / «360 total secure» / «Dr.Web» / «Avast»
2. Перезагрузите ПК и попробуйте снова.
3. После удаления / отключения служб защиты проблема должна быть устранена.
