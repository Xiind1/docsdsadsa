# Arknights: Endfield

<details>

<summary><strong>VISUALS</strong></summary>

* **ESP** — Отображение объектов через стены
* **Show Offscreen** — Показать объекты вне экрана
* **Debug Names** — Отладочные имена объектов
* **Max Distance** — Максимальная дистанция отображения
* **Radar** — Радар на экране
* **Character Filters** — Фильтры персонажей
* **Collectable Filters** — Фильтры собираемых предметов
* **Builder Mode** — Режим билдера esp (можно самому добавить любой предмет)

</details>

<details>

<summary><strong>COMBAT</strong></summary>

* **Damage Changer** — Изменение урона
* **Kill Aura** — Аура убийства
* **Rapid Fire** — Быстрая стрельба
* **Dumb Enemies** — "Глупые" враги
* **Magnetizer** — Притягивание врагов

</details>

<details>

<summary><strong>PLAYER</strong></summary>

* **Noclip** — Режим без коллизий
* **Infinite Stamina** — Бесконечная выносливость
* **Godmode** — Режим бессмертия
* **Remove Skill CD** — Удаление отката способностей
* **Fill Ultimate** — Заполнение ультимативной способности
* **Peeking Effect** — Эффект подглядывания
* **Auto Loot -** автоподбор лута
* **Loot Filters** — Фильтры подбираемого лута

</details>

<details>

<summary><strong>TELEPORTS</strong></summary>

* **Quest Teleport** — Телепорт к заданиям
* **Entity Teleport** — Телепорт к сущностям
* **Custom TP Points** — Пользовательские точки телепортации
* **Loop Mode** — Режим цикла
* **Draw Target** — Отрисовка цели
* **Draw Points** — Отрисовка точек

</details>

<details>

<summary><strong>UTILITY</strong></summary>

* **FOV Changer** — Изменение поля зрения
* **FPS Unlocker** — Разблокировка FPS
* **Auto Puzzle** — Авто-пазлы
* **Auto Skip Dialogue** — Авто-пропуск диалогов
* **Game Speed** — Изменение скорости игры
* **Custom Crosshair** — Пользовательский прицел
* **Watermark** — Водяной знак

</details>
