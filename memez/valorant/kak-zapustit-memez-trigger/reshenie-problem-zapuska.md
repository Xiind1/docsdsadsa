# Решение проблем запуска

## Лаунчер закрывается без ошибок:

#### Решение: win+r -> введите Prefetch -> удалите содержимое папки

## Триггер перестает стрелять:

#### Решение №1: Смените клавишу стрельбы в настройках игры

#### Решение №2: Обновите привязку клавиши в триггере

## ERROR: DRIVER FAILED

#### Решение:

1. Проверьте наличие FaceIt/GameGuard
2. Удалитей сторонние антивирусы, а встроенный отключите с помощью dcontrol

## Синхронизация времени:

1. Win + I → Время и язык
2. Синхронизировать часы
