Визуалы\
Боты – Подсвечивает NPC-ботов.\
Спящие – Показывает спящих игроков.\
Никнейм – Отображает имена игроков.\
Скелет – Рисует каркас-скелет.\
ID команды – Показывает идентификатор команды.\
Предмет в руках – Отображение: Выкл / Иконка / Текст.\
Быстрые слоты – Отрисовывает хот-бар.\
Расстояние – Печатает дистанцию до игрока.\
Дальность видимости – Макс. дальность ESP (0-400 м).\
Заливка – Тип Chams: Выкл / Сетчатая / Плоская.\
Индикатор вне поля зрения – Стрелки к целям за экраном.\
Дистанция индикатора – Радиус стрелок (0-400 м).\
Труп игрока – Подсветка трупов игроков.\
Труп животного – Подсветка трупов животных.\
Расстояние (трупы) – Показ дистанции до трупов.\
Дальность видимости (трупы) – Радиус ESP трупов (0-400 м).\
Выпавшие предметы – Отображение: Выкл / Иконка / Текст.\
Расстояние (предметы) – Дистанция до лута.\
Дальность видимости (предметы) – Радиус ESP лута (0-400 м).

Наводка\
Включить – Активировать аимбот.\
Игнорировать союзников – Не наводится на тиммейтов.\
Игнорировать спящих – Пропускает спящих.\
Проверка видимости – Работает только по видимым целям.\
Тип наводки – Невидимая (Silent) или Через мышку (Mouse).\
Кость – Голова / Грудь / Бедро / Ближайшая.\
Кнопка наводки – Горячая клавиша (только режим Mouse).\
Радиус поиска цели – Угол захвата (10-500).\
Скорость наводки – Скорость мыши (1-10, режим Mouse).\
Макс. дистанция – Дистанция наведения (10-400 м).\
Радиус работы – Рисует круг FOV.\
Цель наводки – Подсвечивает выбранную цель.\
Прицел – Рисует статический прицел.

Ресурсы\
Кусок камня / Кусок металла / Кусок серы / Кусок дерева – Подсветка больших жил.\
Собираемые руды / Собираемое дерево / Конопля / Дизель / Цветы – Подсветка мелких ресурсов.\
Расстояние – Показывает дистанцию до ресурсов.\
Дальность видимости – Радиус ESP (0-400 м).\
Еда – Дикие объекты еды (есть ползунки Distance / Visibility).\
Ящики / Коробки / Бочки – Лут в монументах (Distance / Visibility).\
Воздушный ящик / Ящик чинук – События аирдропа (Distance / Visibility до 2000 м).

Мир\
Наземный транспорт / Водный транспорт / Воздушный транспорт / Поезда – ESP транспорта.\
Расстояние / Дальность видимости – Параметры для транспорта.\
Шкаф / Хранилища / Верстак – Базовые объекты (с Distance / Visibility).\
Расставные ловушки / Наземные ловушки – Турели, капканы.\
NPC вертолеты / Брэдли / Грузовое судно – Событийные объекты (Distance / Visibility).\
Животные / Лошадь / Полоска здоровья – Подсветка фауны (Distance / Visibility).

Прочее\
Оружие: Минимизировать отдачу / Минимизировать разброс / Без раскачки / Автоматический / Легкая EOKA / Улучшения ближнего боя.\
Освещение: Яркий мир / Установка время мира (+ ползунок Час 1-23).\
Движение: Полет (Выкл / Режим ускорения / Режим полёта) и Клавиша флайхака.\
Постройки: Удалить ближайшие стены + Клавиша удаления стен.\
Полет камерой (РИСК), Скорость камеры, Клавиша камеры – Свободная камера.

Радар\
Включить – Активировать радар.\
Показывать ботов / Показывать спящих – Доп. сущности.\
Направление взгляда / Никнейм / Дистанция – Подписи точек.\
Дальность отрисовки – Радиус радара (50-400 м).\
Размер – Размер окна (50-200 px).

Цвета\
Палитры для Игрок, Боты, Союзник, Спящий игрок, Видимый скелет, Невидимый скелет, Труп, Ресурсы, Мир, Животные, Элементы наводки.

Настройки\
Язык – English / Русский.\
Клавиша меню / Клавиша выгрузки – Горячие клавиши меню и выгрузки чита.\
Ресурсы: Включить привязку ESP ресурсов / Переключить ESP ресурсов.\
Мир: Включить привязку ESP мира / Переключить ESP мира.
