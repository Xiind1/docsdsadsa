## **1. Подготовка системы к запуску продукта**&#x20;

### **1. Отключение Безопасности Windows**

* Перейдите в параметры системы (вы можете нажать комбинацию WIN + I)
* Откройте **Безопасность Windows**
* Отключите параметр **"Защита в реальном времени" и остальные параметры защиты**

<figure><img src="../.gitbook/assets/image (140).png" alt=""><figcaption></figcaption></figure>

2. **Окончательно отключите Безопасность Windows с помощью программы dControl**

* **Google Drive** - [ссылка для загрузки](https://drive.google.com/file/d/19G3C5Gg1KDr1W05jhwwB6xeMx8PG_IrU/view?usp=sharing) (пароль 1234)
* **Yandex Disk** - [ссылка для загрузки](https://disk.yandex.ru/d/pLPzChHbwskWNQ) (пароль 1234)
* **Mega** - [ссылка для загрузки](https://mega.nz/file/Vr9EUSKB#Sn0bze9l49paasaCZqYPkAodQwo5avSpUWVzo5f4x38)

<figure><img src="../.gitbook/assets/image (141).png" alt=""><figcaption><p><strong>Нажмите "</strong><mark style="color:red;"><strong>Отключить Защитник Windows</strong></mark><strong>"</strong> </p></figcaption></figure>

3. **Отключите изоляцию ядра.**

* Параметры => Обновление и безопасность => Безопасность Windows => Безопасность устройства => Сведения об изоляции ядра

### **2. Удаление конфликтующего программного обеспечения**

Следующие программы необходимо **полностью удалить**, а не просто закрыть:

* Faceit AC, Riot Vanguard, ACE (AntiCheatExpert). Данные античиты препятствуют запуску наших читов. Для ABI и Delta Force удалять ACE античит не нужно.
* Любой сторонний антивирус (Avast, Kaspersky, McAfee, ESET, Bitdefender и т. д.)

{% hint style="danger" %}
Если установлены античиты из списка или сторонний антивирус, продукт **не будет работать** независимо от других настроек.
{% endhint %}

{% hint style="danger" %}
**ПОСЛЕ ВСЕХ ДЕЙСТВИЙ ПЕРЕЗАГРУЗИТЕ ПК**

### 3. Прочие Настройки

* В некоторых играх, запускаемых через Steam, нужен включенный игровой оверлей (вызывается комбинацией Shift + Tab). По умолчанию он включен, но если у вас его нет, активируйте его в настройках Steam.
* Для использования чита на Dark and Darker сначала необходимо проделать следующие действия:
  * Если вы используете клиент Steam: перейдите в Библиотека -> Dark and Darker -> Свойства. Введите **-dx11** в поле "Параметры запуска" и сохраните. Это необходимо для работы софта.
  * Если вы используете Blacksmith Launcher, то откройте лаунчер -> Иконка лаунчера сверху слева -> Game -> Launch option. Вставьте **-dx11** в это поле и сохраните. Это необходимо для работы софта.
* Для Phoenix Full Rust. Требуется скачать и установить [Bandicam](https://www.bandicam.com/ru/). Запустите программу от имени Администратора. Дальше запуск чита в обычном порядке.
* Для Phoenix Rob Run External. Требуется скачать и установить [Bandicam](https://www.bandicam.com/ru/). Запустите программу от имени Администратора. Дальше запуск чита в обычном порядке.
* Для софта на DBD. Зайдите в игру без чита и установите режим экрана "**Без Рамок**" или "**Оконный**", в "**Полный экран**" софт на DBD работать не будет.
* Для ABI Full. Нужно зайти в папку с игрой, и перейти в следующую папку (пример пути для Steam, для других лаунчеров аналогично): **D:\SteamLibrary\steamapps\common\ABInfinite\ABInfinite\Binaries\Win64**\
  В данной папке нужно создать текстовый файл guid.txt (текстовый файл с названием guid) и вставить туда чужой ID аккаунта ABI. Чужой ID вы можете легко получить в игре в профиле другого игрока, через чат или таблицу лидеров. Данный шаг необходимо проделать для корректной работы софта и встроенного спуфера.&#x20;

## 2.Установка и запуск чита

1. Установите лоадер - [https://mega.nz/folder/e5xX0Dwb#V0yFv-QAzbjaKoOOM7bzyQ](https://mega.nz/folder/e5xX0Dwb#V0yFv-QAzbjaKoOOM7bzyQ)

{% hint style="info" %}
Если не скачивается файл, то используйте VPN
{% endhint %}

2. Запустите скачанный лоадер от имени администратора.

{% hint style="danger" %}
Перед запуском лоадера обязательно убедитесь, что все игры закрыты. Строго не рекомендуется запускать лоадер при наличии открытых игр!
{% endhint %}

3. При первом запуске нужно будет активировать ваш ключ. Вставьте свой ключ в поле "**Key**" и нажмите "**Continue**".

<figure><img src="../.gitbook/assets/image (417).png" alt=""><figcaption></figcaption></figure>

4. После небольшой загрузки произойдёт авторизация в лоадере и перед вами появится его основная вкладка. Здесь вы можете выбрать софт для запуска, посмотреть дату окончания подписки и статус.

<figure><img src="../.gitbook/assets/image (418).png" alt=""><figcaption></figcaption></figure>

5. Теперь в разделе "**Game**" выбираем игру для запуска и жмём "**Launch**".

{% hint style="info" %}
* Чит для Marvel Rivals на данном этапе попросит вас указать путь до лаунчера игры. Далее игра запустится автоматически.
* При запуске ABI Chams на данном этапе нужно будет выбрать режим работы софта, введите 1 или 2 в консоли и нажмите Enter, в зависимости от нужного вам режима работы.
{% endhint %}

6. Начнётся процесс запуска чита, ждём появления сообщения "**Wait for the game process**".

<figure><img src="../.gitbook/assets/image (419).png" alt=""><figcaption></figcaption></figure>

7. После появления соответствующего сообщения необходимо запускать вашу игру.
8. Инжект произойдёт автоматически, в главном меню игры появится меню чита.
9. Поздравляем, вы успешно запустили чит!

{% hint style="info" %}
Далее меню чита открывается/закрывается нажатием клавиши **Insert**. В Hunt Chams нажатие Insert меняет режим работы чамсов.

В ABI Chams / Delta Force Chams / Apex X-Ray / Hunt Chams / Rust Chams меню отсутствует, весь функционал работает автоматически после запуска.

При запуске ПО для Dark and Darker, Marvel Rivals, ABI Full спуфер запускается автоматически во время инжекта, дополнительные действия проделывать не нужно. Инструкция к спуферу для других игр представлена ниже.
{% endhint %}

## Запуск Спуфера (опционально)

Инструкция по использованию спуфера и запуску читов вместе с ним:

1. Во-первых, учтите этот момент:
   * Если вы хотите использовать спуфер вместе с нашим ПО, то сначала нужно запускать именно его.
   * Если вы хотите использовать наш спуфер вместе с другим ПО (из другого лоадера), то спуфер нужно запускать после чита, до запуска игры.
2.  Для запуска спуфера откройте лоадер от имени администратора и выберите "**Spoofer**" в окне "**Game**", далее нужно нажать "**Launch**".<br>

    <img src="https://cdn.wh-satano.ru/satano-spoofer-s1.webp" alt="Запуск спуфера в лоадере" height="288" width="697">
3.  Сначала спуфер спросит вас, хотите ли вы полностью очистить следы после предыдущих блокировок. Нажмите "**Yes**', если вы ещё не очищали следы после получения последнего бана. Если вы хотите просто спуфнуться, то нажмите "**No**".<br>

    <img src="https://cdn.wh-satano.ru/satano-spoofer-s2.webp" alt="Полная очистка системы после бана" height="286" width="699">
4.  Полная очистка следов банов занимает какое-то время. После неё ваш ПК будет перезагружен и нужно будет продолжить процесс спуфа со следующего шага.<br>

    <img src="https://cdn.wh-satano.ru/satano-spoofer-s3.webp" alt="Процесс полной очистки следов банов" height="286" width="695">
5.  После нажатия "**No**" начинается процесс подмены данных вашего ПК. Он также занимает некоторое время.<br>

    <img src="https://cdn.wh-satano.ru/satano-spoofer-s4.webp" alt="Процесс подмены данных ПК (Спуфинга)" height="284" width="703">
6. По окончании подмены данных вы получите оповещение об успешном спуфе. Лоадер полностью закроется. Далее действия следующие:
   * Если вы запускаете спуфер вместе с одним из читов Phoenix / Satano, то нужно будет заново открыть лоадер и просто запускать чит по инструкции.
   *   Если вы запускаете спуфер вместе с читом из другого лоадера или без чита вовсе, то уже можно переходить к запуску игры.<br>

       <img src="https://cdn.wh-satano.ru/satano-spoofer-s5.webp" alt="Успешная подмена данных системы" height="283" width="700">
7. Приятной игры!

{% hint style="info" %}
Для проверки работы спуфера можно сделать скриншот вкладки "**Device Information**" до и после успешного спуфа. Используйте полную очистку только после получения бана, нет нужды делать её каждый раз.
{% endhint %}
